# display_d1 / display_d2 基板構成・配線ガイド

## 1. 全体像

表示系は Seeed Studio XIAO ESP32-C3 を 2 台使った構成です。`display_d1` が主表示・通信基板、`display_d2` が表示用センサー入力基板です。両基板は I2C で接続し、D2 で測定した値を D1 が取得して TFT に表示します。

```text
RS485 / Modbus RTU                  I2C (400 kHz)
logger ----------------> display_d1 <--------------> display_d2
                           |                           |
                           |                           +-- ポテンショメータ x2
                           |                           +-- バッテリー電圧入力
                           |                           +-- 超音波距離センサー
                           |
                           +-- TFT (速度・高度表示)
                           +-- DPS310 (気圧・温度)
                           +-- ESP-NOW 風速受信
```

両基板と接続するセンサーの GND は必ず共通にします。XIAO ESP32-C3 の GPIO は 3.3 V ロジックです。TFT、RS485 トランシーバー、超音波センサーの電源電圧と信号レベルは、それぞれのモジュール仕様に合わせて確認してください。5 V 出力の信号を XIAO の GPIO へ直接入力してはいけません。

## 2. display_d1: 主表示・通信基板

### 役割

- 240 x 320 の ST7789 TFT に対気速度と高度を表示する。
- RS485/Modbus RTU のスレーブとして logger から対気速度とロール警報を受け取る。Slave ID は `2`、通信速度は `9600 bps / 8N1`。
- display_d2 を I2C スレーブとして定期ポーリングし、ポテンショメータ、バッテリー ADC 値、超音波高度を取得する。
- DPS310 から気圧高度を取得する。
- Modbus の対気速度が 2 秒以上更新されない、または値が 0 の場合は、ESP-NOW で受信した風速を表示に使う。

### XIAO ESP32-C3 のピン割り当て

| 接続先・用途 | XIAO 表記 | GPIO | 信号方向 | 補足 |
|---|---:|---:|---|---|
| RS485 トランシーバー DE/RE | D3 | GPIO5 | 出力 | 送受信方向制御。DE と /RE を同じ信号で制御する構成を想定。 |
| RS485 トランシーバー RO | D7 | GPIO20 | 入力 | UART0 RX。トランシーバーの受信出力を接続。 |
| RS485 トランシーバー DI | D6 | GPIO21 | 出力 | UART0 TX。トランシーバーの送信入力を接続。 |
| I2C SDA | D4 | GPIO6 | 双方向 | display_d2 と DPS310 の SDA を並列接続。 |
| I2C SCL | D5 | GPIO7 | 出力/双方向 | display_d2 と DPS310 の SCL を並列接続。 |
| TFT SCLK | D8 | GPIO8 | 出力 | SPI クロック。 |
| TFT MISO/SDO | D9 | GPIO9 | 入力 | TFT からの読み出しを使わない場合は未接続でもよい。 |
| TFT MOSI/SDA | D10 | GPIO10 | 出力 | SPI データ。TFT 側では `SDA` と印字される場合がある。 |
| TFT CS | D1 | GPIO3 | 出力 | TFT チップセレクト。コードでは GPIO 番号 `3` を指定。 |
| TFT DC/A0/RS | D0 | GPIO2 | 出力 | コマンド/データ選択。 |
| TFT RST | D2 | GPIO4 | 出力 | TFT リセット。 |

TFT は `TFT_eSPI` の共通設定で ST7789、解像度 240 x 320、SPI ピンは上表の値です。TFT の VCC、GND、BL（バックライト）はスケッチから制御していません。BL 端子があるモジュールは、モジュール仕様に従って常時点灯用の電源へ接続します。

### D1 の I2C バス

I2C は `SDA = GPIO6 (D4)`、`SCL = GPIO7 (D5)`、400 kHz で動作します。D1 がマスターです。

| 接続機器 | I2C アドレス | 用途 |
|---|---:|---|
| display_d2 | `0x30` | センサー値の読み出し、ロール警報値の書き込み |
| DPS310 | `0x76` | 気圧・温度の測定、気圧高度の算出 |

I2C の SDA/SCL には適切なプルアップが必要です。モジュール側にプルアップ抵抗が実装済みの場合、複数モジュールを接続して抵抗値が小さくなりすぎないように注意します。

## 3. display_d2: 表示用センサー入力基板

### 役割

- 2 個のポテンショメータとバッテリー電圧を ADC で読み取る。ポテンショメータは 10 サンプル移動平均を適用する。
- UART 接続の超音波距離センサーに 300 ms ごとに測定コマンドを送り、距離を cm に換算する。
- I2C スレーブ（アドレス `0x30`）として、D1 からの要求にセンサー値を返す。
- D1 から受け取るロール警報に応じて TFT 表示とブザー音を変更する。

### XIAO ESP32-C3 のピン割り当て

| 接続先・用途 | XIAO 表記 | GPIO | 信号方向 | 補足 |
|---|---:|---:|---|---|
| ポテンショメータ 1 の可変端子 | A0 | GPIO2 | 入力 | 0～3.3 V の範囲に収める。 |
| ポテンショメータ 2 の可変端子 | A1 | GPIO3 | 入力 | 0～3.3 V の範囲に収める。 |
| バッテリー電圧監視 | A2 | GPIO4 | 入力 | 必ず分圧回路を介し、ADC 入力を 3.3 V 以下にする。 |
| ブザー | D3 | GPIO5 | 出力 | ロール警報音と起動音を出力。 |
| 超音波センサー RX | D6 | GPIO21 | 出力 | XIAO からセンサーへ送る UART0 TX。 |
| 超音波センサー TX | D7 | GPIO20 | 入力 | センサーから XIAO へ戻る UART0 RX。 |
| I2C SDA | D4 | GPIO6 | 双方向 | display_d1 の D4 と接続。 |
| I2C SCL | D5 | GPIO7 | 出力/双方向 | display_d1 の D5 と接続。 |
| TFT SCLK | D8 | GPIO8 | 出力 | D1 と同じ TFT_eSPI 設定。 |
| TFT MISO/SDO | D9 | GPIO9 | 入力 | 読み出しを使わない場合は未接続可。 |
| TFT MOSI/SDA | D10 | GPIO10 | 出力 | SPI データ。 |
| TFT CS/DC/RST | D1/D0/D2 | GPIO3/GPIO2/GPIO4 | 出力 | TFT の CS/DC/RST。 |

## 4. 基板間の配線

display_d1 と display_d2 の間は、次の 4 本を基本として接続します。

| display_d1 | display_d2 | 説明 |
|---|---|---|
| D4 / GPIO6 / SDA | D4 / GPIO6 / SDA | I2C データ線 |
| D5 / GPIO7 / SCL | D5 / GPIO7 / SCL | I2C クロック線 |
| GND | GND | 信号基準。必須。 |
| 3V3 または各基板の電源 | 3V3 または各基板の電源 | 同一電源で給電する場合のみ接続。電源方式を混在させない。 |

## 5. I2C で受け渡すデータ

通常の読み出しは D1 から D2 へ行い、D2 は以下をリトルエンディアンの `uint16_t` で返します。

| バイト | 内容 |
|---:|---|
| 0-1 | ポテンショメータ 1 ADC 値 |
| 2-3 | ポテンショメータ 2 ADC 値 |
| 4-5 | バッテリー電圧 ADC 値 |
| 6-7 | 超音波距離 [cm] |

D1 から D2 への書き込みは 1 バイトです。`0` は通常、`1` は左ロール警報、`2` は右ロール警報を表します。

## 6. 現行コードの重要な注意点

1. **I2C ペイロード長が一致していません。** D2 は上表の 8 バイトだけを書き出しますが、D1 と双方の設定ヘッダーは 12 バイトを要求しています。D1 は受信長が 12 バイトでなければ通信失敗として扱うため、現状では D2 の値を正常取得できません。運用前に、両方を 8 バイトに統一するか、D2 側を 12 バイト送信に拡張してください。
2. **D2 のステータス LED と TFT MOSI が D10/GPIO10 で重複しています。** D2 は起動時に D10 をステータス LED として High にしますが、同じピンは TFT の MOSI です。外付け LED をこのピンにつなぐと SPI 信号を乱すため、LED は別の未使用 GPIO へ移すか、LED 機能を使用しないでください。
3. **D2 の TFT CS/DC/RST は ADC 入力と同じ GPIO 番号です。** 共通の TFT 設定では CS=GPIO3、DC=GPIO2、RST=GPIO4 で、D2 では A1=GPIO3、A0=GPIO2、A2=GPIO4 でもあります。このままでは TFT と ADC 入力が競合します。D2 に TFT を実装する場合は、TFT の CS/DC/RST または ADC の割り当てを変更して重複を解消してください。D2 の TFT を使用しない構成なら、`g_tft` の初期化・描画処理を外す選択もあります。
4. D1 の RS485 と D2 の超音波センサーはいずれも UART0 の D6/D7 を使いますが、別々のマイコン上の回路なので基板間で結線しません。UART の信号名は「送信側 TX を受信側 RX へ」交差接続します。

## 7. 組み立て・動作確認の順序

1. すべての GND が共通であること、GPIO に 5 V が直接入らないことをテスターで確認する。
2. D1/D2 間の I2C（D4-D4、D5-D5、GND-GND）だけを接続し、I2C アドレス `0x30` が応答することを確認する。
3. I2C ペイロード長を統一してから、D1 のシリアル出力で `i2c=OK` になることを確認する。
4. D1 の DPS310 と TFT を単体確認する。
5. D1 の RS485 を接続し、logger から Slave ID `2` へ対気速度・ロール警報を書き込む。
6. D2 の ADC、超音波センサー、ブザーを順に追加して確認する。

この順序にすると、電源・I2C・表示・RS485 のどこで問題が起きているかを切り分けやすくなります。
